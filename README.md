# Awesome lists [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

A list of awesome lists I've found useful, grouped by topic. Each one is a curated collection in its own right, so this is a good place to start when you're looking for tools in an area.

## Contents

- [Accessibility](#accessibility)
- [Testing and quality](#testing-and-quality)

## Accessibility

- [awesome-accessibility](https://github.com/lukeslp/awesome-accessibility) by Luke Steuber - Accessibility resources, tools and best practices, from standards and laws to testing engines, screen reader testing and plain language.

## Testing and quality

- [awesome-test-automation](https://github.com/brandonhimpfen/awesome-test-automation) by Brandon Himpfen - Frameworks, tools and libraries for automating software testing.
- [awesome-testing](https://github.com/brandonhimpfen/awesome-testing) by Brandon Himpfen - Testing frameworks, tools and resources for every level of software testing.
- [awesome-qa](https://github.com/brandonhimpfen/awesome-qa) by Brandon Himpfen - Quality assurance tools, frameworks and communities.

## Contributing

Know a list that belongs here? Open a pull request. Please add it to the right section in alphabetical order, with the author's name and a one-line description.
